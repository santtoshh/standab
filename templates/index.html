Add one row per operator. For multi-operator analysis, add a row for each. The report will include per-operator results and a combined bundle with a built-in dataset toggle.

Data requirements

One row per ride. Column names are flexible. Common aliases are auto-detected across operators.

  • ✓ Vehicle identifier vehicle_id
  • ✓ Ride start & end timestamps ISO 8601 or YYYY-MM-DD HH:MM:SS UTC
  • ✓ Ride start & end coordinates WGS-84 decimal degrees as start_lat/start_lng/end_lat/end_lng, or GeoJSON start_loc/end_loc
